# Security Policy

## Supported Versions

Since T-Phisher is an open-source penetration testing and intelligence framework, security updates are applied to the main branch continuously.

| Version | Supported          |
| ------- | ------------------ |
| 2.x     | :white_check_mark: |
| 1.x     | :x:                |

## Reporting a Vulnerability

We take the security of T-Phisher seriously. If you discover a security vulnerability, bug, or flaw within this repository, please follow responsible disclosure practices:

1. **Do Not** open a public GitHub issue for security vulnerabilities.
2. Please report security issues directly by opening a private discussion or contacting the maintainer via email at `support@tphisher.sec` (or through the repository owner's profile contact).
3. We will review the report and work on a patch as quickly as possible.
